## Создание проекта в CODESYS

1. Установить **Device Repository** ОВЕН: таргет `SPK210-07-CS` с [owen.ru](https://owen.ru/codesys).
2. **File → New Project** → Device: `SPK210-07-CS`.
3. Добавить модули I/O (как на схеме):
   - `MV210-214` × 2 (A3, A4)
   - `MU210-403` × N (по количеству на шине)
   - `MU210-502 (см. Замена_MU210-5024.md) или не добавлять` × 1 (аналог уровня, резерв)
   - **Без физического СПК210:** см. [`Пункт3_без_контроллера.md`](Пункт3_без_контроллера.md)
4. Импортировать объекты из `import/`:
   - Создать DUT: `E_WorkMode`, `E_LevelState`, `ST_ScheduleSlot` — скопировать из `DUT_Types.txt`
   - GVL: `GVL_IO`, `GVL_Process`, `GVL_HMI`, `GVL_Schedules` — см. [`Как_добавить_GVL.md`](Как_добавить_GVL.md)
   - FB: `FB_LevelMonitor`, `FB_Schedule`, `FB_ManualMode`, `FB_AutoMode` — см. [`Как_добавить_FB.md`](Как_добавить_FB.md)
   - PRG: `PRG_Main` (назначить Task Main, цикл 20–50 мс)
5. **I/O Mapping** — сопоставить `GVL_IO` с каналами МВ210/МУ210 по `IO_Map.txt` — см. [`Пункт5_IO_Mapping.md`](Пункт5_IO_Mapping.md)
6. Настроить **WebVisu** / встроенный Web-сервер СПК210 для удалённого управления — см. [`HMI/WebVisu_Настройка.md`](HMI/WebVisu_Настройка.md).
7. **OwenCloud** (опционально) — удалённый мониторинг и загрузка проекта.

## Логика (кратко)

### Ручной режим (SA1…SA7 → «Ручн. вкл.»)
- Запуск без защиты сухого хода и без контроля сети.
- SA8/SA9 + SA8.1/SA9.1 — открытие/закрытие M2, M3.
- SA10/SA11 — M4/M5 открыты в ручном, закрыты в «0».
- SA12 — У.Ф.; SA13 — компрессор (только ручной).

### Автоматический режим
- Ожидание верхнего уровня → работа между средним и нижним.
- Нижний уровень или затопление → полная остановка.
- Н1, Н3 — через УПП; Н4–Н6, М1 — по расписанию (`GVL_Schedules`).
- M4 — долив по 3 датчикам; M5 — по затоплению.
- Подсветка — таймер при работе системы.

### Требует уточнения у заказчика
- Логика M2/M3 в автомате (в проекте: открыты при работе).
- Временные окна для каждого насоса.
- Интеграция подсветки (Tuya/RF — вне ПЛК, только KM11).
