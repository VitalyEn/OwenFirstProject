# Пункт 3 README: модули I/O без физического СПК210

Физический контроллер **не нужен**, чтобы добавить модули в проект CODESYS. Они описывают конфигурацию щита; загрузка в ПЛК — отдельный шаг (п. 7 README), когда устройство появится.

---

## Что нужно установить (один раз)

1. **CODESYS V3.5 SP17 Patch 3** (как у СПК210-07).
2. **Device Repository ОВЕН** — таргет `SPK210-07-CS`:  
   https://owen.ru/codesys → раздел «Сервисное ПО» / Device Repository.
3. **Шаблоны модулей Mx210** для CODESYS 3.5 (МВ210-214, МУ210-403, МУ210-502):  
   https://owen.ru/forum/showthread.php?t=31176  
   Версия пакета должна совпадать с вашей SP (например 3.5.11.13).

После установки: **Tools → CODESYS Installer** или распаковка `.package` → перезапуск CODESYS.

Проверка: в мастере **Add Device** в списке есть `MV210-214`, `MU210-403`, `MU210-502`.

---

## Состав по схеме щита ЩУ

| Модуль | Кол-во | На схеме | Назначение |
|--------|--------|----------|------------|
| MV210-214 | 2 | A3, A4 | Дискретные входы (DI) |
| MU210-403 | 4–6* | несколько шин | Дискретные выходы (DO) |
| MU210-502 | 1 | A5 | Аналог 4–20 мА (задание частоты/скорости) |

\* Точное число **МУ210-403** — по количеству блоков на принципиальной схеме (листы 3–5). Минимум: модули у цепей DO для насосов, кранов, У.Ф.

## Пошагово в Device Tree (пункт 3)

### 1. Создайте или откройте проект

- **File → New Project** → `SPK210-07-CS`, язык ST.
- Или откройте `Насосы Крым Обучение.project` в корне проекта — в нём уже может быть настроен СПК210.

### 2. Найдите узел полевой шины

У СПК210 модули **МВ210 / МУ210** обычно подключаются по **RS-485 (Modbus RTU)**, не «в слот» как у ПЛК210.

В дереве устройств (слева):

```
SPK210-07-CS (или ваше имя)
├── PLC Logic
├── Device
│   ├── COM / RS485 / Modbus Master  ← сюда добавляют модули
│   ├── Network
│   └── ...
```

Если узла Modbus нет:

- Правый клик на **Device** или **SPK210** → **Add Device**.
- Выберите **Modbus Serial Master** / **COM-порт** (как в документации ОВЕН к СПК210).
- В параметрах порта: скорость **9600/19200** (как настроите на объекте), 8N1.

### 3. Добавьте модули

Для **каждого** физического модуля на шине:

1. Правый клик на **Modbus Master** (или шина RS-485) → **Add Device**.
2. В фильтре введите `MV210-214` → выберите устройство → OK.
3. Повторите для второго `MV210-214`.
4. Добавьте нужное количество `MU210-403`.
5. Добавьте один `MU210-502`.

### 4. Настройте адреса Modbus (Station / Slave ID)

Двойной клик по модулю → вкладка **Modbus** / **Общие**:

| Модуль | Рекомендация | Примечание |
|--------|--------------|------------|
| MV210-214 №1 (A3) | адрес 1 | Должен совпадать с **конфигуратором Мх210** на объекте |
| MV210-214 №2 (A4) | адрес 2 | |
| MU210-403 … | 3, 4, 5… | По порядку на шине RS-485 |
| MU210-502 | следующий свободный | |

Без контроллера адреса можно задать **условно** (1, 2, 3…) и уточнить на ПНР. Главное — уникальность и запись в `IO_Map.md`.

### 5. Проверка без загрузки в ПЛК

- **Build → Build** (F11) — проект должен **скомпилироваться**.
- Ошибки «библиотека не найдена» → установите пакет Mx210 с форума ОВЕН, версию под ваш SP.
- Красный значок на модуле в дереве → правый клик → **Update Device** / проверка версии device description.

**Login и Download не выполняйте** — контроллера нет.

### 6. I/O Mapping (подготовка к п. 5 README)

Когда модули в дереве есть:

1. Двойной клик **MV210-214** → вкладка **I/O Mapping** (или **Соотнесение входов/выходов**).
2. Появятся каналы `DI1`…`DI32` — их позже свяжете с `GVL_IO` (п. 5 README).
3. То же для **MU210-403** → `DO1`…  
4. Для **MU210-502** → `AO1`…

Без ПЛК привязку можно сделать **вручную в таблице** по `IO_Map.md`, не нажимая «Sync with PLC».

## Как тестировать логику без железа

| Способ | Что даёт |
|--------|----------|
| **Только компиляция** | Проверка синтаксиса ST, библиотек, структуры проекта |
| **Переменные без %I/%Q** | В `GVL_IO` временно не использовать `AT %I*`, а задавать `SA1_Auto`, `LVL_High` вручную в **Watch** при отладке на эмуляторе |
| **WebVisu в браузере** | `PLC_Project/HMI/WebVisu/index.html` — интерфейс без ПЛК (демо) |
| **Симуляция CODESYS** | Если в таргете СПК210 есть **Simulation** (Online → Simulation) — редко полная замена; смотрите в меню Online после Build |
| **СПК210 у ОВЕН / на объекте** | Финальная проверка I/O и Download |

Полноценная эмуляция **всех** каналов МВ210/МУ210 без контроллера ОВЕН обычно **недоступна** — модули отрабатывают только на реальной шине RS-485.

## Частые проблемы

| Симптом | Решение |
|---------|---------|
| Нет MV210-214 в списке Add Device | Установить пакет шаблонов Mx210 с forum.owen.ru |
| Сотни ошибок при компиляции | **Project → Project Settings → Device** — обновить device; **Library Manager → Download missing libraries** |
| Пропала вкладка I/O Mapping у MV210-214 | Обновить device description; версия пакета = версии CODESYS SP |
| Не знаю, сколько MU210-403 | Откройте `Схема.pdf`, посчитайте блоки «МУ 210-403» (листы 3–5) |

## Минимальный порядок работ без СПК210

1. П. 1–2 README — таргет и проект.  
2. **П. 3** — добавить модули в Device Tree (эта инструкция).  
3. **П. 4** — импорт ST из `import/`.  
4. **П. 5** — таблица сопоставления DI/DO по `IO_Map.md` (можно в Excel).  
5. **П. 6** — Visu + `HMI/svg/*.svg`.  
6. При появлении СПК210 — Login → Download → проверка адресов Modbus на реальной шине.
