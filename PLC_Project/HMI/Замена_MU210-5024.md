# Замена MU210-5024 в проекте CODESYS

## Важно

В каталоге ОВЕН и в пакете шаблонов Mx210 **нет** устройства **MU210-5024** / **МУ210-5024**.

На принципиальной схеме (лист 8) у блока A5 указаны линии **4-20 mA** к **УПП (UZ1)** — это **аналоговые выходы** (задание частоте), а не входы уровня.

Типичная опечатка на схеме: **5024** вместо **502**.

---

## Чем заменить

| Задача на объекте | Модуль ОВЕН | В CODESYS / конфигураторе |
|-------------------|-------------|---------------------------|
| 4-20 mA **на УПП** (как на схеме) | **MU210-502** (6 AO) | Шаблон из Mx210Templates, Owen Configurator Mx210 |
| Аналоговый **ввод** 4-20 mA (датчик) | **MV210-102** или **MV210-101** (AI, Ethernet) | Тот же пакет Mx210 |
| Ввод 4-20 mA по **RS-485** (шина с МВ210-214) | **MV110-8.2AS** / **MV110-24.8AS** | Конфигуратор Mx110, Modbus RTU |
| Только 3 дискретных уровня XT4 | **не нужен** | Уровни уже на **MV210-214** (DI44-46) |

**Не путать:**
- **MU210-502** — аналоговый **вывод** (AO)
- **MV210-102** — аналоговый **ввод** (AI)
- **MU210-403** — дискретный **вывод** (реле), не аналог

Снят с производства: **MU210-501** — заменен на **MU210-502**.

---

## Рекомендация для щита ЩУ

### Вариант 1 (по схеме, задание на УПП)

1. В проекте вместо MU210-5024 добавить **MU210-502**.
2. Настроить в **Owen Configurator** (линейка Mx210, Ethernet).
3. В CODESYS: Modbus TCP / устройство Mx210 — **MU210-502**, каналы AO1-AO4 на УПП1/УПП2.
4. В программе — масштабирование задания частоты (отдельный FB, если УПП не по дискретным DO).

### Вариант 2 (только дискретные уровни — текущая логика PLC)

Модуль **можно не добавлять** в Device Tree:

- `LVL_High`, `LVL_Mid`, `LVL_Low` — дискретные входы **MV210-214**
- Переменная `Disp_LevelPct` в HMI считается по трем датчикам

Пункт README про MU210-5024 — **резерв / уточнить с заказчиком**.

### Вариант 3 (аналоговый датчик уровня вместо трех поплавков)

- **MV210-102** (8 AI, 4-20 mA) по Ethernet к СПК210
- Или **MV110-8.2AS** по RS-485 на той же шине, что МВ210-214

## Owen Configurator

Модули **Mx210** (Ethernet) настраиваются в **Owen Configurator**, не в «конфигураторе Мх110»:

- Скачать с страницы Mx210 на owen.ru
- Подключение: Ethernet или USB (microUSB) к модулю
- Видео: https://owen.ru/media/video/podklychenie_moduley_codesys35

Шаблоны CODESYS: https://owen.ru/forum/showthread.php?t=31176 (MU210-502 есть с версии 3.5.11.9).
