## 1. Подготовка проекта

### 1.1 Что должно быть в Application до Visu

| Объект | Откуда взять | Зачем |
|--------|--------------|-------|
| `GVL_HMI` | `import/GVL_HMI.txt` | Все теги для экранов |
| `PRG_HMI` | `import/PRG_HMI.txt` | Заполняет `Disp_*`, `Status_*` из `GVL_IO` |
| `PRG_Main` | `import/PRG_Main.txt` | Логика щита |
| `GVL_IO`, `GVL_Process` | `import/` | Входы/выходы и режимы |

### 1.2 Добавить PRG_HMI в задачу

1. **Application** → **Task Configuration** → **MainTask** (или ваша циклическая задача, 20–50 мс).
2. В списке вызовов должны быть **в таком порядке**:
   - `PRG_Main();`
   - `PRG_HMI();`
3. Если `PRG_HMI` нет — **Add Call** → выберите `PRG_HMI`.

> Без `PRG_HMI` на экранах будут «замёрзшие» нули, даже если Visu собрана правильно.

### 1.3 Библиотека визуализации

В **Library Manager** должна быть подключена стандартная библиотека **VisuElems** / **Visualization** (обычно добавляется с таргетом CODESYS).  
Если в палитре нет Rectangle, Circle, Frame Control — **Add Library** → `VisuElems`.

## 2. Visualization Manager

### 2.1 Создать менеджер

1. В дереве: **Application** → раздел **Visualization**.
2. Правый клик **Visualization** → **Add Object** → **Visualization Manager**.
3. Имя оставьте по умолчанию или `VisuManager`.

### 2.2 Свойства Visualization Manager

Двойной клик **Visualization Manager** → вкладка настроек (названия могут отличаться в RU/EN):

| Параметр | Значение |
|----------|----------|
| **Target visualization** | включить (галочка) |
| **Web visualization** | включить |
| **Start visualization** | `Visu_Main` |
| **Size** / размер | **800 × 480** |

### 2.3 Web Visualization (размер клиента)

В подузле **Web Visualization** (или в свойствах менеджера):

| Параметр | Значение |
|----------|----------|
| **Use specified client size** | да |
| **Client width** | 800 |
| **Client height** | 480 |

Подробнее про доступ по сети: `HMI/WebVisu_Настройка.md`.

Правый клик **Visualization** → **Add Object** → **Visualization** (повторить 5 раз):

| Имя объекта | Назначение |
|-------------|------------|
| `Visu_Main` | Главная |

### 3.2 Размер каждого экрана

Для **каждого** `Visu_*`:

1. Двойной клик → откроется **Visu Editor** (холст).
2. Меню **Visualization** → **Properties** (или правый клик по пустому месту → Properties).
3. **Size**: **Width = 800**, **Height = 480**.
4. **Background color** (если без SVG): RGB **10, 22, 40** (см. палитру ниже).

## 4. Общие приёмы в Visu Editor

Координаты в таблицах: **X, Y, ширина×высота** в пикселях от левого верхнего угла экрана 800×480.

> Эта инструкция отредактирована под **CODESYS 3.5.17.20 (RU, Овен)**.  
> В этой версии в редакторе Visu часто **нет меню `Insert/Вставка`** — элементы добавляются через **панели**.

### 4.0 Какие панели включить (чтобы всё получилось)

Верхнее меню **Вид**:

- **Панель элементов** (Toolbox): где выбирать `Image`, `Rectangle`, `Ellipse/Circle`, `Text`, `Button`.
- **Свойства** (Properties): где задавать `X/Y/Width/Height`, переменную, анимации.

Если не видно слева/справа панелей — включите их через **Вид → Панели** (или **Вид → Окна**; названия в Овен могут отличаться).

### 4.1 Палитра цветов

| Имя | RGB | Когда использовать |
|-----|-----|-------------------|
| BG | 10, 22, 40 | Фон |
| Panel | 19, 34, 56 | Карточки, панели |
| OK | 46, 196, 182 | Автомат, уровень OK |
| Run | 76, 201, 240 | Насос работает |
| Manual | 233, 196, 106 | Ручной режим / ключ |
| Alarm | 231, 111, 81 | Авария |
| Off | 74, 95, 115 | Стоп, неактивно |

### 4.2 Вставить SVG-фон (на каждый экран)

> **В CODESYS 3.5 (Овен) в редакторе Visu часто нет меню Insert / Вставка.**  
> Используйте **палитру элементов**, **Image Pool** или **перетаскивание** — см. [§4.2.1](#421-как-вставить-фон-без-меню-insert).

| Экран | Файл |
|-------|------|
| `Visu_Main` | `HMI/svg/Visu_Main_bg.svg` |
| `Visu_Pumps` | `Visu_Pumps_bg.svg` |
| `Visu_Valves` | `Visu_Valves_bg.svg` |
| `Visu_Levels` | `Visu_Levels_bg.svg` |
| `Visu_Settings` | `Visu_Settings_bg.svg` |

После размещения: **X=0, Y=0**, **Width=800, Height=480** → правый клик → **Order → Send to back** → снять **Selectable**.

#### 4.2.1 Как вставить фон без меню Insert

**Способ A — Image Pool (рекомендуется для Овен)**

1. Дерево: **Visualization** → правый клик → **Add Object** → **Image Pool** (Пул изображений).
2. Двойной клик **Image Pool** → **Add** / **Добавить** → выберите `Visu_Main_bg.svg` (повторите для всех `*_bg.svg`).
3. Откройте `Visu_Main` (двойной клик — редактор холста).
4. Слева включите **Toolbox** / **Панель элементов**: меню **View → Toolbox** (Вид → Панель элементов), если панели нет.
5. В палитре найдите **Image** / **Изображение** / **Bitmap** → клик по холсту или перетащите на холст.
6. Справа **Properties** → поле **Image** / **Filename** / **Картинка** → `...` → выберите запись из **Image Pool** (не «файл с диска», если SVG не подхватывается).
7. X=0, Y=0, 800×480 → **Send to back**.

**Способ B — перетаскивание**

1. Откройте `Visu_Main` в редакторе.
2. Перетащите `Visu_Main_bg.svg` из **Проводника Windows** прямо на **белый холст**.
3. Если CODESYS не принимает SVG — экспортируйте тот же макет в **PNG 800×480** (Inkscape / браузер) и перетащите PNG.

**Способ C — фон всей визуализации (без элемента Image)**

1. Клик по **пустому** холсту (ничего не выделено).
2. **Properties** → **Background** / **Фон** → тип **Image** → файл `Visu_*_bg.svg` или PNG.
3. Минус: сложнее ставить элементы «поверх»; для динамики удобнее способ A.

**Способ D — только цвет (без картинки)**

Если SVG не импортируется: **Background color** RGB **10, 22, 40** и собирайте экран из Rectangle/Text по координатам из §5–9.

**Если SVG не открывается**

Таргет СПК210 иногда не показывает SVG в рантайме. Конвертация: Inkscape → Export PNG → 800×480 → добавить PNG в Image Pool.

### 4.3 Привязать переменную BOOL (лампочка / LED)

1. Откройте `Visu_*` (например `Visu_Main`).
2. Слева **Панель элементов (Toolbox)** → выберите:
   - **Ellipse / Эллипс** (для круглой лампочки), или
   - **Rectangle / Прямоугольник** (если делаете «квадратный LED»).
3. Кликните по холсту — элемент появится.
2. Разместите по координатам из таблицы экрана.
4. Выделите элемент → справа **Свойства** → найдите поле, где задаётся переменная (варианты в Овен):
   - **Переменная** / **Variable**
   - **Вход** / **Input**
   - **Input variable**
   Нажмите **`...`** → выберите `Application → GVL_HMI → нужная переменная` (например `Disp_LvlHigh`).
5. Цвет по условию:
   - **Свойства → Анимации (Animations)** → **Цвет / Color**
   - Условие: `GVL_HMI.<переменная>` (или `= TRUE`)
   - Цвет ON: `Run` или `OK`, иначе `Off`.

### 4.4 Текст со значением переменной

1. Слева **Панель элементов** → **Text / Текст** → клик по холсту.
2. **Text** → режим **Variable** → `GVL_HMI.Disp_LevelText` (STRING)  
   или **Expression** → например `CONCAT(INT_TO_STRING(GVL_HMI.Disp_LevelPct), '%')`.
3. Шрифт: 12–14 pt, цвет светлый (#E0E0E0).

### 4.5 Видимость элемента (баннер аварии)

1. Выделите элемент (полоса, текст «АВАРИЯ»).
2. **Animations** → **Visibility**:
   - Visible if: `GVL_HMI.Status_Alarm = TRUE`
3. Либо вставьте готовый `Visu_Alarm_banner.svg` на **Y=52**, visibility = `Status_Alarm`.

### 4.6 Переключатель (Toggle) для BOOL

1. Слева **Панель элементов** → элемент **Check box / Флажок** (или **Toggle switch**, если есть).
2. В **Свойствах** задайте переменную: `GVL_HMI.HMI_AutoEnable` (BOOL).
3. Подпись рядом: обычный **Text**.

### 4.7 Кнопка «Сброс аварии» (импульс)

Вариант A — **кнопка с действием**:

1. Слева **Панель элементов** → **Button / Кнопка** → клик по холсту.
2. В **Свойствах** найдите раздел действий/событий (часто называется):
   - **Input actions** / **Действия ввода**
   - **Events** / **События**
3. Настройте:
   - **OnMouseDown / При нажатии**: `GVL_HMI.HMI_ResetAlarm := TRUE`
   - **OnMouseUp / При отпускании**: `GVL_HMI.HMI_ResetAlarm := FALSE`  
   (сброс обрабатывает `PRG_Main` по фронту/уровню)

Вариант B — **Toggle** только для теста (не рекомендуется на сдаче).

### 4.8 Полоса уровня (высота от %)

1. **Rectangle** (заливка) внутри рамки резервуара, привязан к низу.
2. **Height** → анимация / выражение:  
   `GVL_HMI.Disp_LevelPct * 1.3`  
   (при 100% высота ≈ 130 px; подгоните множитель под ваш SVG).
3. **Y** можно задавать как `220 - высота` (если низ резервуара на Y=220).

## 13. Куда нажимать в CODESYS (RU/EN)

Разные сборки CODESYS/репозитория ОВЕН могут чуть менять названия пунктов. Ниже — самые частые варианты **RU/EN** и куда именно смотреть.

### 13.1 Если не видно дерева проекта слева

- **View → Project** (EN) / **Вид → Проект** (RU) — показать Project Explorer.
- Если окно есть, но свернуто — восстановите вкладку **Project**.

### 13.2 Где добавить `Visualization Manager`

1. В дереве проекта найдите раздел **Application → Visualization**.
2. Правый клик по **Visualization** →
   - **Add Object…** (EN) / **Добавить объект…** (RU) →
   - **Visualization Manager**.

Если в списке нет:
- убедитесь, что установлен компонент **Visualization** при установке CODESYS;
- проверьте **Library Manager** (должны быть библиотеки визуализации).

### 13.3 Где включить TargetVisu и WebVisu

1. Двойной клик по **Visualization Manager** (или правый клик → **Open** / **Открыть**).
2. В открывшемся окне справа ищите группы свойств (варианты названий):
   - **Target Visualization** / **Целевая визуализация**
   - **Web Visualization** / **Веб-визуализация**
3. Поставьте галочки **Enable/Использовать**.

**Где выбрать стартовый экран:**
- свойство **Start visualization** / **Стартовая визуализация** → `Visu_Main`.

### 13.4 Где задать размер 800×480

Есть **два места**, которые важно не перепутать:

**A) Размер самого экрана (каждый `Visu_*`):**
- откройте `Visu_Main` (двойной клик) →
- клик по пустому месту холста →
- справа **Properties / Свойства** →
- **Size / Размер** → 800×480.

**B) Размер клиента WebVisu (в Visualization Manager / WebVisu):**
- откройте **Visualization Manager** →
- раздел **Web Visualization** →
- включить **Use specified client size** / **Использовать заданный размер клиента** →
- 800×480.

### 13.5 Где добавить `PRG_HMI` в MainTask

1. В дереве проекта: **Application → Task Configuration** / **Конфигурация задач**.
2. Откройте **MainTask** (двойной клик).
3. Найдите список вызовов (варианты):
   - **POUs** / **Программы**
   - **Program calls** / **Вызовы программ**
4. Нажмите **Add call…** / **Добавить вызов…**:
   - добавьте `PRG_Main`
   - добавьте `PRG_HMI`
5. Перетащите мышью или кнопками вверх/вниз, чтобы **`PRG_HMI` был после `PRG_Main`**.

### 13.6 Где вставить SVG на фон (без Insert)

Меню **Insert** в редакторе Visu у Овен часто **отсутствует**. Делайте так:

1. **Visualization → Add Object → Image Pool** → добавить `Visu_Main_bg.svg`.
2. Открыть **Visu_Main** → **View → Toolbox** (Панель элементов).
3. Из палитры: **Image** / **Изображение** → клик на холст.
4. Properties → **Image** → из Image Pool; X=0, Y=0, 800×480.
5. Правый клик по картинке → **Order → Send to back** / **На задний план**.

Альтернатива: перетащить файл с диска на холст. Не работает SVG → PNG 800×480.

### 13.7 Где привязать переменную к элементу (LED/текст)

У разных элементов разные поля, но логика одна:

1. Выделите элемент (Circle / Rectangle / Text).
2. Справа откройте **Properties / Свойства**.
3. Найдите поле:
   - **Input** / **Вход**
   - **Variable** / **Переменная**
   - **Text (variable/expression)** / **Текст (переменная/выражение)**
4. Нажмите **`...`** и выберите `Application → GVL_HMI → нужная переменная`.

### 13.8 Где настраивается видимость/цвет по условию (анимации)

1. Выделите элемент.
2. В свойствах откройте вкладку/группу:
   - **Animations** / **Анимации**
   - **Visualization → Animations** (иногда отдельная панель)
3. Добавьте:
   - **Visibility** / **Видимость** → условие `GVL_HMI.Status_Alarm`
   - **Color** / **Цвет** → условие `GVL_HMI.Disp_N1_Run` и т.п.

### 13.9 Где задать действие кнопки «перейти на экран»

Вариант 1 (если есть **Frame Control**):
- **Insert → Frame Control** / **Вставка → Управление кадром**
- В свойствах выбираете **Target visualization** / **Целевая визуализация**.

Вариант 2 (обычная кнопка):
1. **Insert → Button** / **Вставка → Кнопка**.
2. Properties → **Input actions / Действия ввода** (или Events/События).
3. **OnMouseClick / При щелчке**:
   - Action: **Switch visualization** / **Переключить визуализацию**
   - Target: `Visu_Pumps` (и т.д.)

### 13.10 Где посмотреть ошибки/почему Visu не обновляется

- **Build → Build** (F11) — компиляция.
- Если на экране не меняется индикация:
  - проверьте, что вы привязали элементы к `GVL_HMI.*`, а не к `GVL_IO.*`;
  - проверьте, что `PRG_HMI` реально вызывается в MainTask.

## 14. Сквозной пример: собрать `Visu_Main` за ~10 минут (клик‑лист)

Этот раздел — максимально практичный. Делайте **по порядку**, не перепрыгивая шаги.

### 14.0 Перед стартом

- Убедитесь, что в проекте есть `GVL_HMI` и `PRG_HMI`.
- Проверьте, что `PRG_HMI` добавлен в **MainTask** и стоит **после** `PRG_Main`.
- Убедитесь, что объект `Visu_Main` создан и открывается в редакторе.

### 14.1 Открыть `Visu_Main` и поставить размер

1. В дереве проекта: **Visualization → Visu_Main** → двойной клик.
2. Клик по пустому месту холста → справа **Properties**.
3. **Size**: Width=800, Height=480.

### 14.2 Поставить SVG‑фон

1. **Image Pool** → Add → `HMI/svg/Visu_Main_bg.svg` (или PNG 800×480).
2. **Visu_Main** → палитра **Toolbox** → элемент **Image** на холст.
3. Properties → Image из пула; X=0, Y=0, Width=800, Height=480.
4. Правый клик → **Send to back**; **Selectable** = выкл.

(Меню Insert в Visu Editor у Овен обычно нет — см. §4.2.1.)

### 14.3 Шапка (заголовок + режим)

#### A) Заголовок

1. **Insert → Text**.
2. Позиция: X=12, Y=14.
3. Static text: `ЩУ · Насосы Крым`.

#### B) Плашка режима (фон + текст)

1. **Insert → Rectangle**.
2. Позиция: X=520, Y=10, размер 120×32.
3. Цвет Fill базовый: OK (46,196,182).
4. **Animations → Color**:
   - условие: `GVL_HMI.Status_Manual`
   - TRUE: Manual (233,196,106)
   - FALSE: OK (46,196,182)
5. Добавьте Text поверх прямоугольника (X=530, Y=18) двумя вариантами:
   - Text `Ручной`, Visibility: `GVL_HMI.Status_Manual`
   - Text `Автомат`, Visibility: `NOT GVL_HMI.Status_Manual`

### 14.4 Баннер аварии

1. **Insert → Image** → `HMI/svg/Visu_Alarm_banner.svg`.
2. X=0, Y=52, Size 800×26.
3. **Animations → Visibility**: `GVL_HMI.Status_Alarm`.
4. Text `АВАРИЯ` (X=12, Y=56), Visibility тоже `Status_Alarm`.

### 14.5 Датчики уровня (4 строки LED)

Сделайте одну строку и скопируйте 3 раза.

**Шаблон строки:**

1. **Insert → Circle** (LED), размер 12×12.
2. Variable / Input: `GVL_HMI.Disp_LvlHigh` (для первой строки).
3. **Animations → Color**:
   - TRUE: OK
   - FALSE: Off
4. Рядом Text: `Верхний`.

**Копирование:**

- Строка 2: `Disp_LvlMid`, текст `Рабочий`, цвет TRUE=OK
- Строка 3: `Disp_LvlLow`, текст `Нижний`, цвет TRUE=Alarm
- Строка 4: `Disp_Flood`, текст `Затопление`, цвет TRUE=Alarm

### 14.6 Карточка насоса (сделать Н1 и размножить)

1. Соберите карточку Н1 (заголовок + 2–3 LED).
2. Привяжите LED:
   - Run → `GVL_HMI.Disp_N1_Run` (TRUE=Run)
   - Manual → `GVL_HMI.Disp_N1_Manual` (TRUE=Manual)
   - Alarm → `GVL_HMI.Disp_N1_Alarm` (TRUE=Alarm)
3. Скопируйте карточку для Н3/Н4/М1 и замените переменные на соответствующие `Disp_*`.

### 14.7 Нижнее меню (переходы)

1. Добавьте 5 кнопок (Frame Control или Button).
2. Для каждой задайте действие **Switch visualization**:
   - Главная → `Visu_Main`
   - Насосы → `Visu_Pumps`
   - Краны → `Visu_Valves`
   - Уровни → `Visu_Levels`
   - Настройки → `Visu_Settings`
3. Скопируйте меню на остальные `Visu_*` (чтобы не делать 5 раз).

### 14.8 Быстрая проверка (без объекта)

В Watch/Force (если доступно) задайте в `GVL_HMI`:

- `Status_Alarm := TRUE` → баннер должен появиться
- `Disp_N1_Run := TRUE` → индикатор RUN на Н1 должен загореться
- `Disp_LvlMid := TRUE` → LED «Рабочий» должен загореться

Если ничего не меняется — почти всегда причина одна из двух:
- `PRG_HMI` не вызывается в MainTask
- элементы привязаны не к `GVL_HMI.*`, а к другим переменным
