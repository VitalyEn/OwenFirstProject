# SVG-фоны для CODESYS Visu (800x480)

Готовые подложки для **СПК210-07**. Размер каждого файла: **800 x 480 px** (кроме баннера аварии).

> Кодировка файла: UTF-8. В редакторе: Reopen with Encoding - UTF-8.

## Файлы

| SVG | Экран CODESYS | Назначение |
|-----|---------------|------------|
| `Visu_Main_bg.svg` | Visu_Main | Главная: резервуар, датчики, 4 карточки насосов |
| `Visu_Pumps_bg.svg` | Visu_Pumps | Сетка насосов Н1-Н6, М1 |
| `Visu_Valves_bg.svg` | Visu_Valves | Краны М2-М5, У.Ф., компрессор, свет |

| `Visu_Alarm_banner.svg` | все экраны | Полоса аварии 800x26 (поверх фона) |

## Если CODESYS пишет «файл повреждён»

Старые версии файлов могли содержать:

- **нулевой байт** внутри XML (часто `Visu_Valves_bg.svg`);
- символ **SUB (0x1A)** в тексте;
- неэкранированный **`&`** в строках (`SA1&SA7` — нужно `SA1&amp;SA7`);
- **битую кириллицу** (CP1251 сохранён как UTF-8).

В репозитории файлы **пересобраны**: UTF-8, валидный XML, подписи латиницей (русский текст — в элементах Visu поверх фона).

Если ошибка остаётся: удалите картинку из **Image Pool** → **Add** заново из этой папки, либо экспортируйте SVG в **PNG 800×480**.

## Импорт в CODESYS 3.5 (Овен) — без меню Insert

В редакторе Visu **нет пункта Insert → Image**. Используйте один из способов:

### Способ 1 — Image Pool (рекомендуется)

1. **Visualization** → ПКМ → **Add Object** → **Image Pool**.
2. Двойной клик Image Pool → **Add** → выберите `Visu_Main_bg.svg`.
3. Откройте **Visu_Main** (двойной клик).
4. **View → Toolbox** (Вид → Панель элементов) — если слева пусто.
5. В палитре: **Image** / **Изображение** → клик на холст.
6. **Properties** → **Image** → `...` → запись из Image Pool.
7. X=0, Y=0, Width=800, Height=480.
8. ПКМ по картинке → **Order → Send to back**; **Selectable** = off.

### Способ 2 — перетаскивание

Перетащите `.svg` или `.png` из Проводника на холст `Visu_Main`.

### Способ 3 — фон экрана

Клик по пустому холсту → **Properties → Background → Image** → файл с диска.

### SVG не открывается

Экспорт **PNG 800×480** (Inkscape / Figma) → добавить PNG в Image Pool.

## Поверх фона

Динамика из `GVL_HMI`: Rectangle, Circle, Text, Frame Control (тоже из **Toolbox**, не Insert).

Баннер `Visu_Alarm_banner.svg`: Y=52, Visibility := `GVL_HMI.Status_Alarm`.
