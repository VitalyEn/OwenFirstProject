# Исходный код Structured Text

Файлы для копирования в CODESYS находятся в каталоге **`import/`**:

| Файл | Объект в CODESYS |
|------|------------------|
| `DUT_Types.txt` | DUT: E_WorkMode, E_LevelState, ST_ScheduleSlot |
| `GVL_Process.txt` | GVL_Process |
| `GVL_Schedules.txt` | GVL_Schedules (RETAIN) |
| `FB_LevelMonitor.txt` | FB_LevelMonitor |
| `FB_Schedule.txt` | FB_Schedule |
| `FB_ManualMode.txt` | FB_ManualMode |
| `FB_AutoMode.txt` | FB_AutoMode |
| `PRG_Main.txt` | PRG_Main (Main Task) |
| `GVL_IO.txt` | GVL_IO — входы/выходы, DK_QF, FB_KM*, концевики |
| `PRG_HMI.txt` | PRG_HMI (обновление переменных визуализации) |
| `GVL_HMI.txt` | GVL_HMI — переменные HMI/WebVisu |

Копии для справки: каталог **`source/`** (GVL_IO, PRG_HMI).

Карта привязки каналов: **`IO_Map.txt`** (DI1…DI32, DO1…DO24).

## GVL_IO

Полный текст — в `import/GVL_IO.txt`. Включает:

- ключи SA1…SA14, уровни LVL_*, Flood;
- **DK_QF1, DK_QF2…DK_QF11, DK_QF18, DK_QF19** (QF12–17 на схеме нет);
- обратную связь VFD*, FB_KM*, концевики M2…M5;
- команды CMD_KM*, CMD_VFD*.

## Порядок вызова

```
PRG_Main
  → FB_LevelMonitor
  → CASE WorkMode: Manual / Auto
       → FB_ManualMode / FB_AutoMode
```
