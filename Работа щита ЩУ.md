Краткое описание.

У щита ЩУ будет два варианта управления:

1 Ручной

2 Автоматический

Ручной:

Ручной режим предназначен для сервисного запуска. Всё оборудование запускается без защит по сухому ходу и параметров сети. Переводом ключей (SA1…SA7) оборудование переходит в режим включено. Ключи SA8 и SA9 в ручном режиме предоставляют ручное управление для открытия и закрытия шаровых кранов М2 и М3 посредством переключения ключей SA8.1 и SA9.1 в положение открыть и закрыть. Ключи SA10 и SA11 при переводе в ручной режим сразу открывают задвижки М4 и М5, при переводе в положение “0” закрывают. Ключ SA12 включает У.Ф установку при переводе в ручной режим и отключает в положении “0”. Ключ SA13 включает и отключает компрессор промывки (режим только ручной)

Автоматический режим:

Автоматический режим работает по временным отрезкам на оборудовании Н1, Н2, Н3, Н4, Н5, Н6, М1. Оборудование Н1 работает под управлением частотного преобразователя.

На оборудовании М2 и М3 требуется уточнение логики.

Оборудование М4 работает на долив по трём уровням (три датчика)

Оборудование М5 срабатывает по затоплению.

В автоматическом режиме оборудование ждёт полного наполнения по верхнему уровню, в последующем работает по рабочему уровню между средним и нижним аварийным уровнем.

При срабатывании нижнего аварийного уровня всё оборудование останавливается (защита от сухого хода). При затоплении оборудование также останавливается.

Подсветка работает по таймеру.

На базе контроллера (СПК210-07-CS Owen) управления щита ЩУ есть web сервер позволяющий управлять в автоматическом режиме через браузер. С аппаратов защиты и коммутационных устройств на контроллер заведены положения, удалённо можно увидеть вкл/откл оборудования и уровень по датчикам. Для связи установлен роутер. Для работы роутера требуется SIM карта или подключение по Wi-fi. Работа подсветки построена на контроллере. Контроллер предлагает комплексное управление через три интерфейса: Tuya WiFi (приложение Intelligent Arlight), RF 2.4G (с помощью пультов SMART-SPI) и Push-Dim для управления с помощью возвратных нажимных выключателей. Основные возможности включают сегментное управление цветом через приложение (с функциями заливки цветом, точечного окрашивания и стирания участков), 44\* предустановленных и более 10\* пользовательских сценариев с 16\* вариантами динамических эффектов.
